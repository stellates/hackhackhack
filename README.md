# THE HOLLYWOOD HACKER (猛烈打鍵！ハリウッド・ハッカー)

ドラマやハリウッド映画に登場する「キーボードを猛烈な勢いで叩いて何でも解決する天才ハッカー」になりきれる、30秒間のブラウザ向け短編ネタタイピングゲームです。

![The Hollywood Hacker](https://via.placeholder.com/1200x630/05080c/00ff88?text=THE+HOLLYWOOD+HACKER)

---

## 🎯 コンセプト

> **「正しく打つな、激しく叩け！」**

- 重要なのは**タイピングの正確さではなく、どれだけ凄腕ハッカーっぽく激しく打鍵できるか**。
- キーボードのどのキーを叩いても、画面には映画さながらのLinuxカーネルエクスプロイト、量子暗号解読、アセンブリコードが猛烈な勢いで出力されます。
- 打鍵速度、怒涛の連打、そして時折スッと打鍵を止める**「劇的なタメ（間）」**をAIがリアルタイム判定！
- 終了時にはハッカー適性スコア、面白い称号、クスッと笑えるAIツッコミ寸評を表示。
- 結果は**高画質認定証PNG画像**としてワンクリックで保存可能です。

---

## 🚀 主な機能・演出

1. **ハリウッド映画風マルチウィンドウUI**
   - CRTモニターの走査線（スキャンライン）演出
   - メインコードストリーム（C言語・Rust・Assembly・Pythonコード）
   - メモリHexダンプ解読アニメーション
   - リアルタイム脅威レーダー（Canvas描画）
   - システムログ＆ドラマチック警告バナー（BLACK ICE DETECTED! など）
2. **完全内製のWeb Audio API効果音**
   - 外部音声アセット不使用（著作権クリア・軽量）
   - メカニカルキーボード風打鍵クリック音
   - Enterキー強打時のヘビーな重低音ボム
   - 警報サイレン音、カウントダウン音、侵入成功時のサイバーファンファーレ
   - 音声ミュート切り替え対応
3. **独自のハリウッド打鍵採点エンジン**
   - 最高瞬間速度（Peak KPS）
   - 平均打鍵速度（Avg KPS）
   - 映画的タメ判定（連打後に0.4〜1.8秒スッと静止するハリウッド仕草を検知してボーナス加点）
   - Enterキー強打回数、最大コンボ数
   - プレイスタイルに応じたユニークな称号＆AIツッコミ寸評
4. **結果画面のPNG画像保存**
   - HTML5 Canvasによる1200×675pxの高解像度認定証（Incident Report）自動生成
   - ワンクリックでPNG保存、SNS共有テキストコピー機能
5. **マルチデバイス対応**
   - PCの物理キーボード打鍵を最優先に最適化
   - スマートフォン・タブレット向けの「RAPID HACK（連打）」バーチャルボタン搭載

## 🛠 技術スタック

- **言語**: TypeScript (Strict Mode)
- **ビルドツール**: Vite 6+
- **描画**: HTML5 Canvas (レーダー描画、認定証PNG生成)
- **オーディオ**: Web Audio API (プロシージャル音声合成)
- **外部依存ライブラリ**: ゼロ（ランタイム依存なし・ローカル完結）
