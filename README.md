# THE HOLLYWOOD HACKER v2.0 (猛烈打鍵！ハリウッド・ハッカー)

ドラマやハリウッド映画に登場する「キーボードを猛烈な勢いで叩いて何でも解決する天才ハッカー」になりきれる、30秒間のブラウザ向けサイバーリズム・タイピングゲームです。

## 🎯 コンセプト (v2.0大型アップデート)

> **「正しく打つな、激しく叩け！…だが拍子（リズム）を外すな！」**

v2.0では、映画ハッカーの「猛烈なキーボードガチャガチャ」に加え、**音ゲー（リズムアクション）の爽快なタイミング判定と難易度選択**が融合！

- **Web Audio APIによる本格サイバーシンセBGM (BPM 128)** に合わせて、流れてくるサイバーノーツを見極めろ！
- **二段式サイバー・ハイウェイ（Dual Highway）**:
  - **上段（SHIFTレーン）**: 大文字や記号キー入力を再現するパープルレーン！連打中にも並行して流れてくる！
  - **下段（TYPINGメインレーン）**: 単語連打（BURST）、語間スペース（SPACE）、行末実行（ENTER）が本物のプログラミングの呼吸で流れる！
- **選べる3つの難易度 (EASY / NORMAL / HARD)**:
  - 🟢 **EASY**: 初心者向け。Shiftはなし〜終盤ほんの少し。単語連打→Space→Enterの王道タイピングリズムで爽快プレイ！
  - 🔵 **NORMAL**: 中級者向け。Shift頻度が上がり、連打と並行した2レーン打鍵の楽しさを体験！
  - 🔴 **HARD**: 上級ハッカー向け。怒涛の単語連打とSpace、要所のEnter、そしてBURST連打中に襲いかかる怒涛のShift同時並行打鍵！
- **終了後の難易度変更対応**:
  - ゲーム終了後、「🎚️ 難易度を変更する」ボタンでいつでもスタート画面に戻り、別のレベルに挑戦可能！
- **開始前「3・2・1」カウントダウン & 2秒のウォーミングアップ余白**: 落ち着いてキーボードに指を構えてから突入可能！
- 終了時にはハッカー適性スコア、同期率（Sync Rate %）、面白い称号、クスッと笑えるAIツッコミ寸評を表示。
- 結果は**高画質認定証PNG画像**としてワンクリックで保存可能です。

## 🚀 主な機能・演出

1. **選べる3つの難易度（EASY / NORMAL / HARD）**
   - プレイスタイルに合わせてスタート画面でワンクリック切り替え
   - 難易度ごとにノーツの流れる速度、譜面密度、判定幅、スコア倍率が変化
2. **サイバー・ビート・ハイウェイ（Rhythm Highway）**
   - ターミナル上部を流れるネオンノーツレーン
   - PERFECT / GREAT / GOOD / MISS / PENALTY のリアルタイムタイミング判定
   - 判定に応じたネオン演出・グリッチ画面フラッシュ
3. **完全内製のプロシージャル・サイバーBGM & 効果音**
   - 外部音声ファイルゼロ（著作権クリア・超軽量）
   - キック、スネア、ハイハット、アシッドベース、アルペジオシンセがBPM 128でグルーヴ
   - メカニカルキーボード打鍵音、Enter重低音ボム、警報サイレン音
4. **厳格かつ爽快なハリウッド採点エンジン**
   - 最高打鍵速度（Peak KPS）
   - リズム同期率（Sync Rate %）
   - PERFECT / GREAT / GOOD / MISS / PENALTY集計
   - 劇的タメ（Dramatic Pauses）、Enter強打数
   - 難易度・プレイスタイル・ミス傾向に応じたユニークな称号＆AIツッコミ寸評
5. **結果画面の高画質認定証PNG保存**
   - HTML5 Canvasによる1200×675px認定証（Incident Report）自動生成
   - 難易度バッジ、スコア、同期率、称号を刻印
   - ワンクリックPNGダウンロード、SNS共有テキストコピー
6. **マルチデバイス対応**
   - PCキーボード打鍵最適化（フッターにキーガイド表示）
   - スマートフォン・タブレット向けのオンスクリーンボタン完備

## 🛠 技術スタック

- **言語**: TypeScript (Strict Mode)
- **ビルドツール**: Vite 6+
- **描画**: HTML5 Canvas (レーダー描画、認定証PNG生成)
- **オーディオ**: Web Audio API (プロシージャル音声合成)
- **外部依存ライブラリ**: ゼロ（ランタイム依存なし・ローカル完結）
